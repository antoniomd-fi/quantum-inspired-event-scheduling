# Notebooks

This folder contains reproducible notebooks used to inspect experiment outputs.

Planned folders:

- `livebook`: Elixir Livebook notebooks.
- `jupyter`: Python/Jupyter notebooks for analysis and plotting.

Current notebooks:

- `livebook/results_exploration_es.livemd`: Spanish standard-library Livebook
  for inspecting v2, QAOA, and v3 result summaries from curated CSV outputs.
- `livebook/results_exploration_en.livemd`: English version for the public
  experimental artifact.
